# CleanPause Privacy Policy

Effective date: October 8, 2026. Publisher: Evgenii ALEKSEEV.

CleanPause does not send personal information to the publisher or external
servers. It has no advertising, analytics, telemetry, account registration,
or application network communication.

## Local information

CleanPause stores settings and diagnostic logs on the user's device. Settings
include reminder schedules, cleaning duration, appearance, and language
preferences. Logs record application events and errors and may contain local
file paths, including a Windows profile name. Logs are not uploaded automatically.
The application reads the Windows profile language to select its interface
language. A manual language preference is stored in the current user's registry.

## Keyboard and mouse

CleanPause temporarily blocks keyboard and mouse input during a cleaning session
explicitly started by the user. It does not record keystrokes, mouse activity,
screen contents, or the contents of other applications. Elevation is requested
through Windows UAC for the input-blocking function.

## Control and support

Local settings and logs can be deleted by the user after closing the application.
Storage locations for the EXE version are documented in the project README;
Windows manages storage for the MSIX version. The EXE installer preserves settings
and logs on uninstall.

Support is available at https://github.com/admeugene-prog/CleanPause/issues.
GitHub processes information submitted through its services under its own privacy
policy. Public issues are visible to others; do not post private information.
If you choose to share a diagnostic log, review and remove personal paths first.
Microsoft Store and Windows services operate under their respective privacy
policies; this policy describes the CleanPause application itself.

Updates to this policy will be published on this page with a revised effective date.

# Политика конфиденциальности CleanPause

Дата вступления в силу: 8 октября 2026 года. Издатель: Evgenii ALEKSEEV.

CleanPause не отправляет персональные данные издателю или внешним серверам.
Приложение не содержит рекламы, аналитики, телеметрии, регистрации аккаунтов
и сетевого обмена.

Настройки и диагностический журнал хранятся локально. Настройки включают
расписание, длительность очистки, оформление и язык. Журнал содержит события
и ошибки приложения и может включать локальные пути с именем профиля Windows.
Журнал автоматически не отправляется. Приложение читает язык профиля Windows;
выбранный вручную язык хранится в реестре текущего пользователя.

Блокировка клавиатуры и мыши включается во время сеанса, явно запущенного
пользователем. Приложение не записывает нажатия клавиш, движения мыши,
содержимое экрана или других приложений. Для блокировки ввода используется
запрос повышения прав через Windows UAC.

После закрытия приложения пользователь может удалить локальные настройки
и журнал. Пути EXE-версии указаны в README; хранением MSIX-версии управляет
Windows. Установщик EXE сохраняет настройки и журнал при удалении приложения.

Поддержка: https://github.com/admeugene-prog/CleanPause/issues.
Обращения в GitHub обрабатываются по его собственной политике конфиденциальности.
Публичные обращения видны другим людям; не публикуйте личные данные.
Перед добровольной отправкой журнала удалите из него личные пути.
Microsoft Store и службы Windows имеют собственные политики; эта политика
описывает само приложение CleanPause.

Изменения политики публикуются здесь с обновлённой датой вступления в силу.
