# Установщик CleanPause

Готовый файл: `dist/CleanPause-Setup.exe`.

Перед установкой закройте CleanPause через «Выход» в трее. Запустите
установщик: приложение будет скопировано в `%LOCALAPPDATA%\CleanPause`.
Установка выполняется для текущего пользователя без административных прав.
Само приложение при запуске по-прежнему может запросить UAC для BlockInput.

Создаётся ярлык в меню «Пуск»; ярлык на рабочем столе можно выбрать.
Удаление доступно через «Установленные приложения» Windows. Обновление
и удаление сохраняют config.json, журнал и выбор языка пользователя.
После первого запуска из установленной папки путь автозапуска обновляется
согласно настройке приложения. Удаление убирает автозапуск, если он указывает
на удаляемую установленную копию.

Приложение, установщик и встроенный деинсталлятор подписаны локальным
сертификатом CleanPause Local Code Signing. Системное доверие к CA
установщик не изменяет.

Повторная сборка: `./build-installer.ps1`. Скрипт собирает и подписывает
приложение, затем создаёт установщик. Inno Setup 6.7.3 скачивается из
[официального релиза](https://jrsoftware.org/isdl.php), проверяется его
Authenticode-подпись и распаковывается в переносном режиме в
`%LOCALAPPDATA%\CleanPauseBuildTools\InnoSetup-6.7.3`.

Проверены компиляция, подписи и запрет установки при работающем приложении:
тестовая установка остановилась до копирования файлов с сообщением о
запущенном экземпляре. Полный цикл установки/удаления на этом компьютере
не выполнялся, поскольку пользовательская копия CleanPause работает.
