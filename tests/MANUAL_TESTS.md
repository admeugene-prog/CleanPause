# Протокол приёмочных испытаний CleanPause

Дата подготовки: 08.10.2026. Автоматические результаты — в `AUTOMATED_RESULTS.md`. Эта таблица является планом ручных проверок, а не утверждением об их выполнении.

Для каждой ОС заполнить: версия и build Windows, процессор, устройства ввода, DPI, мониторы, пользовательские права, версия/хеш EXE, результат, наблюдения, проверяющий и дата. Испытания реальной блокировки проводить в тестовом сеансе после сохранения работы, с доступной физической клавиатурой для Ctrl+Alt+Del. Начинать с длительности 1 минута. Для аварийного завершения/зависания worker использовать внешнее управление тестовым ПК; обычный локальный ввод во время блокировки не предназначен для этих действий.
