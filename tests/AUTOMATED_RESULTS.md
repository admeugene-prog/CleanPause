# Результаты проверки

После добавления пользователем исключения в антивирус 08.10.2026 новая сборка с каруселью и баннером успешно собрана и подписана локальным сертификатом Code Signing. Быстрые тесты и vet проходят. Windows видит подпись, но корневой CA пока не входит в системное доверие.

Карусель инструкций и баннер: встроенный Markdown преобразуется в 12 карточек; тест проверяет наличие ключевых шагов, оговорок и рекомендаций производителя, отсутствие Markdown-разметки и корректную длительность. Проверены циклическая навигация, автоматическая смена при CLEANING без изменения таймера/состояния и остановка скрытой карусели. Новый баннер декодируется и создаёт Windows bitmap. Быстрые тесты, vet и сборка проходят. Визуальная приёмка новых окон и DPI требует ручной проверки.

Исправление отсутствующего изображения: тест чтения GDI bitmap выявил пустую заливку после StretchDIBits. Рендер теперь заполняет пиксели DIBSection напрямую и передаёт HBITMAP стандартному контролу SS_BITMAP через STM_SETIMAGE. Тест GetDIBits читает 270 строк и проверяет наличие разнообразных цветов изображения; проходит. Картинка добавлена также в окно подтверждения. Сборка, быстрые тесты и vet проходят. Повторная проверка запуска не выполнялась: smoke-скрипт обнаружил уже работающий CleanPause, который не завершался автоматически.

Обновление аварийного выхода и иллюстрации: worker регистрирует `EVENT_SYSTEM_DESKTOPSWITCH`, обрабатывает очередь сообщений на своём OS-потоке и проверяет доступность input desktop. Терминальное событие `interrupted` останавливает UI; после ручного завершения поздние heartbeat/error игнорируются. Тесты проверяют фиксацию события через обработчик callback (без настоящего Ctrl+Alt+Del), раннее завершение отсчёта, терминальность IPC, сброс состояния GUI и доступность завершения/выхода. Проверена загрузка встроенного PNG, сохранение пропорций и ABI GDI. Физический Ctrl+Alt+Del и визуальная проверка иллюстрации на всех DPI остаются ручными проверками.

Обновление обработки доступа: запуск с `--enable-input` проверяет TokenElevation и при необходимости использует стандартный запрос UAC. Сборка, `go test -short ./...`, `go vet ./...` и проверка запуска после изменения проходят. Добавлены тесты ABI SHELLEXECUTEINFOW, чтения токена текущего процесса и сохранения аргументов с пробелами, кавычками и кириллицей при перезапуске. Реальное повышение через UAC и последующий BlockInput автоматически не запускались; они остаются ручными испытаниями.
