# Локальная подпись CleanPause

Выпущены OpenSSL CA (RSA 4096, SHA-256, 10 лет) и сертификат
CleanPause Local Code Signing (RSA 3072, SHA-256, 1 год, EKU Code Signing).
Цепочка проверена командой OpenSSL verify. Публичные сертификаты:
`root-ca.crt` и `codesign.crt`.

Закрытые ключи, база CA и `codesign.pfx` находятся в
`%LOCALAPPDATA%\CleanPause\Signing`. Ключи и PFX защищены случайным паролем.
`password.dpapi` хранит пароль в зашифрованном виде для текущего пользователя
Windows. Папка доступна текущему пользователю и SYSTEM. Не публикуйте её,
не переносите DPAPI-файл как способ резервного копирования пароля:
он привязан к учётной записи Windows. Потеря доступа к ней может лишить
возможности использовать ключи.

Подписать существующий EXE:

```powershell
.\tools\Sign-Executable.ps1 -Path .\dist\CleanPause.exe
```

Собрать и подписать:

```powershell
.\build.ps1 -Sign
```

Скрипт не устанавливает CA или сертификат в хранилища доверия.
Локальный CA не имеет публичного доверия Windows. Без доверия к CA
Windows может сообщить об ошибке цепочки даже при наличии подписи.
Подпись не гарантирует устранения эвристического обнаружения антивирусом.
Временная метка не добавляется; это локальная подпись, а не готовая схема
публичного распространения с проверенным издателем и timestamp.

08.10.2026 после добавления пользователем исключения в антивирус новая
сборка с каруселью успешно собрана и подписана: `dist/CleanPause.exe`.
Windows обнаруживает сертификат подписи, но сообщает, что цепочка не
достигает доверенного корневого центра. Системное доверие не изменено.

Для повторного выпуска в другой учётной записи/на другой машине:
`.\tools\New-SigningCertificate.ps1`. Скрипт отказывается заменять существующий PFX.
Не запускайте повторный выпуск для продления: для этого нужна отдельная
процедура с сохранением действующего CA.
